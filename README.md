# Visualization of holomorphic functions

![Domain coloring](/media/domain-coloring.png)

## Getting started

If you want to work in your browser, without any install steps

  - Create a new marimo notebook: <https://marimo.app/> 

  - Open the final notebook [here](https://boisgera.github.io/visualization-of-holomorphic-functions/)


## Installation

For more control, install [uv], clone the repository 
of this project and inside its directory, execute either:

```bash
uv marimo edit my-new-notebook.py
```

to start a new notebook or

```bash
uv marimo edit notebook.py
```
 
to edit the final notebook.
